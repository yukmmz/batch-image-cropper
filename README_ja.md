# Batch Image Cropper

*[English](README.md) / 日本語*

**→ [アプリを開く](https://yukmmz.github.io/batch-image-cropper/)**

複数の画像をまとめて切り抜けるブラウザ用ツール。  
アップロードもサーバーも無し — すべてブラウザの中で処理する。

## 機能

- **画像ごとの切り抜き枠** — 各画像が独立した切り抜き枠を持つ
- **揃える機能** — 中心・縦横比・大きさを揃える、または枠をそのまま全画像にコピーする
- **拡大・移動** — `Ctrl/Cmd + スクロール` で拡大縮小、`スクロール` で移動、ダブルクリックで元に戻す
- **使い方（?）** — サイドバー上端の ? ボタン（または `?` キー）で使い方の窓を開く。基本操作・全キーボードショートカット・タッチ操作を載せている
- **全画面** — `F` キーまたは ⛶ ボタン（サイドバー上端）でブラウザの枠を隠し、作業領域を広げる
- **FB** — サイドバー上端の FB ボタンから、ご意見・不具合の報告を開発者に送れる
- **設定（⚙）** — 言語（日本語 / English）、共有用の QR コード、更新履歴、他のアプリへのリンク
- **元に戻す** — 画像ごとの操作履歴（`Ctrl/Cmd + Z`）
- **JSON の書き出し / 読み込み** — 切り抜き枠をファイル名ごとに保存・復元する
- **タッチ対応** — 1本指のドラッグで移動・大きさ変更、ピンチで拡大縮小（iPad / タブレット）
- **保存方法**
  - Chrome / Edge: 選んだフォルダへ直接書き込む（File System Access API）
  - Safari / Firefox: 切り抜いた全画像を `.zip` でダウンロード

## 使い方

1. **Load Images** を押すか、画像ファイルをウィンドウにドラッグ＆ドロップする
2. 赤い切り抜き枠をドラッグして位置を決め、四隅をドラッグして大きさを変える
3. 揃えるボタンで、全画像の枠を揃える
4. **Save Cropped Images** を押して書き出す

### 修飾キー

| キー | 効果 |
|---|---|
| `Shift` ＋ 大きさ変更 | 縦横比を固定 |
| `Ctrl / Cmd` ＋ 大きさ変更 | 中心を基準に大きさを変える |
| `Shift` ＋ 移動 | 横または縦の方向だけに動かす |
| `←` / `→` | 画像を切り替える |
| `Ctrl / Cmd + Z` | 元に戻す |
| `F` | 全画面の切り替え |
| `?` | 「使い方」の窓を開く（? ボタンでも可） |
| `Esc` | 開いている窓を閉じる |

## ローカルで動かす

静的な HTML/CSS/JS — ビルド不要。

```bash
# clone してローカルで配信する
git clone https://github.com/yukmmz/batch-image-cropper.git
cd batch-image-cropper
python3 -m http.server 8000
# その後 http://localhost:8000 を開く
```

テスト（計算部分のみ、ブラウザ不要）: リポジトリ直下で `node --test`。

## 保存データ

- 画像と切り抜き枠はどこにも保存しない。ページを閉じると消える。切り抜き枠を残したいときは **JSON の書き出し** を使う。
- ブラウザの localStorage に残すのは、言語と最後に見たバージョンだけ（`batch-image-cropper/` で始まるキー）。
- 外部に送られるのは、**FB** の窓で「送信」を押したときに書いた内容（とアプリ名・バージョン・表示言語）だけ。画像はどこにも送らない。
- 消したいときは、ブラウザの設定でこのサイトのデータを削除する。

## 対応ブラウザ

| ブラウザ | 保存方法 |
|---|---|
| Chrome / Edge | フォルダへ直接書き込む |
| Safari / Firefox | ZIP でダウンロード |
